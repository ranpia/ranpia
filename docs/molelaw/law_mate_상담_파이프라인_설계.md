# ✅ LawMate 법률상담 AI 시스템 전체 파이프라인

---

## 📋 요구사항 명세서

### 1. 주요 기능 요약

| 기능        | 설명                                                  |
| --------- | --------------------------------------------------- |
| 사용자 질문 입력 | 자연어 기반 법률 질문 수집 (웹/모바일)                             |
| 질문 정제     | GPT 모델을 통해 핵심 키워드/법률적 문장 추출                         |
| 법령 조회     | 국가법령정보센터 API를 통해 관련 법령 실시간 조회                       |
| 판례 조회     | API를 통해 관련 법령 기반 판례 검색 후, GPT가 선택 가능한 형태로 가공           |
| 응답 생성     | GPT가 질문 + 법령 + 판례를 조합하여 상담 응답 생성                    |
| 챗봇 연계     | 후속 질문, 실무 절차 안내, 변호사 추천 등을 제공하는 대화형 인터페이스           |

---

### 2. 시스템 구성요소 (상세)

#### ✅ 프론트엔드
- React 기반 SPA (또는 Next.js 기반 SSR)
- 사용자 입력 폼, 응답 출력 영역, 챗봇 인터페이스 포함
- RESTful API 통신 및 응답 표시

#### ✅ 백엔드 (Spring Boot)
- REST API 서버 구현
- 사용자 질문 수신, GPT API 연동, 외부 API 호출 처리
- 응답 캐싱/로그 저장, JWT 인증 처리 (선택)

#### ✅ 외부 서비스 연동
- OpenAI GPT-4 or GPT-3.5 API
- 국가법령정보센터 API (법령/판례 조회)

#### ✅ DB 구성
- RDB: 사용자 질문 기록, 추천 기록, 상담 히스토리 저장용 (MySQL 등)
- NoSQL: 챗봇 대화 이력 저장용 (예: MongoDB, Redis)
  - 사용자별 대화 세션, 발화별 타임라인, 상태(Context) 관리에 적합
  - 세션별 전개 흐름 추적 및 챗봇 응답 품질 개선에 활용 가능

---

### 3. 데이터 흐름 요약

1. 사용자 질문 입력
2. GPT를 통해 키워드 추출
3. 키워드를 기반으로 법령 조회 (Open API)
4. 해당 법령으로 관련 판례 검색 (Open API)
5. 관련 판례 목록을 GPT에 전달하여 상담 응답 생성에 활용
6. 결과 사용자에게 제공
7. 사용자가 선택 시 챗봇 연동 진행 (추가 질문/추천)

---

### 4. 기술적 고려사항 (상세)

- OpenAPI XML 응답 → 내부에서 JSON으로 변환 처리
- GPT는 Prompt 최적화 기반 호출 (Few-shot 방식 권장)
- 판례 응답은 전체 내용을 전부 사용하지 않고 일부 요약만 포함 (Token 절감)
- 요청 단위 캐싱 고려 (같은 키워드로 반복 요청 시)
- HTTPS 통신 필수 + 사용자 입력 로그 비식별화 필요
- NoSQL 사용 시 채팅방 데이터 스키마 설계 고려 (대화 흐름, 유저 식별, 세션 관리 등)

---

### 5. API 엔드포인트 명세 (초안)

| 메서드    | URI                  | 설명                             |
| -------- | -------------------- | ------------------------------ |
| `POST`   | `/api/consult`       | 사용자 질문 입력 및 GPT 기반 상담 응답 반환    |
| `GET`    | `/api/laws?keyword=` | 키워드를 통한 법령 조문 검색 (국가법령정보센터 연동) |
| `GET`    | `/api/cases?lawId=`  | 법령 ID 기반 판례 조회 (국가법령정보센터 연동)   |
| `POST`   | `/api/gpt/keywords`  | 사용자 질문 → GPT 키워드 추출 요청         |
| `POST`   | `/api/gpt/answer`    | 질문 + 법령 + 판례 → GPT 응답 생성       |
| `POST`   | `/api/chatbot/ask`   | 후속 질문 입력 (챗봇 인터페이스)            |
