## 개발자의 선택을 설명할 수 있는 흐름

### 임시 답변을 빨리 보여주면서 검증·저장 계약 유지

선택의 출발점은 “표시는 먼저 하되 검증된 답변만 저장한다”는 구조다. `answer_delta`는 실제 모델 조각이고 `PREVIEW`는 저장 전 근거 메타데이터다. 길이·인용 검증 뒤 기존 트랜잭션을 통과하면 실제 저장 목록 `SAVED`와 `completed`를 순서대로 보낸다. 실패하면 error로 끝내며 임시 답변을 확정 기록처럼 다루지 않는다. 교정된 답변은 기존 delta와 다를 수 있어 최종 응답 전체로 교체한다.

`InitialAnswerStreamService`는 세마포어로 동시 요청을 제한하고 초과 요청에 `RETRIEVAL_BUSY`를 반환한다. 종료·오류·취소에서 `doFinally`로 슬롯을 반환한다. 내부 작업은 `concatMap`으로 처리하며 heartbeat와 합친 외부 스트림은 completed/error에서 끝난다. 후속 내부 진행 이벤트는 `2354626`에서 별도 merge를 제거하고 동일 sink에 전달하도록 보완했다.

대역 문서는 4개 요청을 유지한 상태에서 5번째가 거절되고 모델 HTTP 호출이 늘지 않았으며, 해제 후 다음 요청이 성공했다고 기록한다. 취소의 미저장·슬롯 재사용도 확인했으나 대역 응답 연결이 즉시 닫히지 않는 경우를 기록했다. 브라우저/TCP 전체 취소나 공급자 계산·청구 중단으로 확대하지 않는다. 이미 동작 중인 동기 HTTP는 timeout까지 남을 수 있고, DB 커밋 후 완료 프레임 전에 연결이 끊기면 저장은 유지된다. 따라서 자동 POST 재시도를 붙이지 않고 저장 목록 재조회로 동기화하는 계약이다.

### 판례 검색의 의도·권한·본문 확보를 별개로 판단

최신 요청이 일반 재설명인지, 기존 판결을 읽으려는지, 새로운 판례를 찾으려는지는 별도 모델이 분류한다. 대화 복원 Advisor는 답변 맥락을 제공하지만 외부 실행 권한을 만들지 않는다. 새 검색은 요청별 명시 동의가 필요하고 서버는 현재 방의 선택 근거·후보 ID·예산을 검사한다.

최신 계약에서는 법령 근거를 자동 선택하지 않는다. 사용자 선택이 없으면 원래 요청으로 검색하고, 여러 법령을 선택하면 모두 맥락에 전달한다. 단일 선택일 때만 참조법령 범위를 선택할 수 있다. 승인을 나타내는 짧은 문장은 기록에 남기되 검색 주제는 앞선 원질문에서 복원한다. 이전 기록의 “항상 법령 한 개를 자동으로 정해 그 법령으로 검색한다”는 설명은 현재 상태로 쓰면 안 된다.

지정 사건은 목록 앞부분만 읽는 대신 후보 메타데이터에서 본문 읽기 대상을 고른다. 목록 선택, 본문 확보, 관련성 리랭크, 실제 읽은 근거의 인용·저장을 구분한다. 검색 범위·전체 페이지 수집·본문 검토량에는 별도 상한이 있고, `searchComplete=false`, 외부 장애, 본문 예산 부족을 판례 부재로 바꾸지 않는다. 긴 판결은 일부 발췌임을 표시하고 원문은 보존한다. 읽은 발췌 밖의 내용까지 검토했다고 주장하지 않는다.

### 인용 교정을 재검색·무제한 재시도로 확장하지 않음

후속 인용 형식이 잘못되면 이미 읽은 같은 근거와 초안을 이용해 1회 교정한다. 교정 Client에는 대화 메모리나 검색·본문 읽기 Tool을 붙이지 않으며 다시 검증해야 저장한다. 손상된 근거 목록은 교정으로 우회하지 않는다. 이 구현은 `eecacd7`에 있고, `189e8cc`의 실모델 **생성 단독 시험** 실패는 앱 후속 교정 성공률을 측정한 것이 아니다.

현재 결과 문서는 같은 모델·프롬프트·검증 규칙의 재실행에서 진단 1건과 정규 15건이 통과했다고 추가 기록한다. 코드 변경 없이 통과한 것이므로 최초 인용 실패가 해결됐다는 증거로 쓰지 않는다. 작은 생성 단독 표본을 전체 RAG 지연·법률 정확도·최대 동시 처리량으로 확장하지 않는다.

## 권한·근거 삭제와 남은 제약

- 스트리밍 요청도 인증·CSRF·방 소유권 계약을 유지한다. JWT 인증은 요청 속성에 저장해 같은 요청의 비동기 재처리에 복원하며 새 세션 인증으로 확장하지 않는다.
- V8 근거 삭제는 원본 스냅샷·해시를 바꾸지 않고 방별 제외 기록을 남긴다. 공유 원문과 다른 방을 보존하고 해당 방의 목록·본문·후속 맥락에서 제외한다. 진행 중인 생성 입력을 소급 취소하지 않으며 과거 답변의 삭제된 근거 링크는 404가 될 수 있다.
- 현재 판례 동의는 법령 자동 선택을 요구하지 않으므로 과거의 “모든 동의 문구에 방 법령 UUID를 포함한다”는 해결책을 최신 계약 전체로 일반화하지 않는다.
- 유효한 인용 ID 검사는 결론의 법적 타당성, 모든 주장에 대한 충분한 인용, 탈옥 방어 성공을 증명하지 않는다. 추천·후속 분류·판례 관련성의 의미 품질과 전체 법률 품질은 별도 검증이다.
