# MoleLaw 공유 대화에서 확인한 설계 의도

## 검색: 생성된 법령명이 아닌 원문 조문에서 근거 찾기

사용자는 법령 API에 ‘민법’을 검색했는데 ‘난민법’이 함께 나오는 부분 일치와, LLM이 존재하지 않는 법령·조항을 만들 수 있는 문제를 설명했다. 법률 하나 안에서도 조문마다 다루는 내용이 달라 질문 의도에 맞는 조문 단위 검색이 필요하다고 판단했다고 밝혔다.

이를 바탕으로 질문을 쟁점으로 나누고 법률 용어로 변환하는 분석, 사용자가 의도 후보를 고르고 없으면 다른 선택지를 받을 수 있는 구상을 설명했다. 이 의도 선택 구상은 2026년 재설계라고 확인했다. 최신 코드의 추천 질문 API·실제 처리 범위는 [상담 흐름 검토](MoleLaw_커밋검토_20261031_상담흐름.md)와 구분해 읽는다. 모든 법령의 수집·색인 완료나 생성 오류 제거를 성과로 단정하지 않는다.

AI Search가 작동하지 않아 제외했다는 사용자 설명은, 원격 문서의 실 API 404 원인 미확인·재시도 보류·기본 QDRANT 유지와 연결한다. 공급자 기능 전체가 작동하지 않는다는 일반적인 판단으로 확대하지 않는다.

## 리랭커: 정답 후보의 존재와 상위 노출을 분리

사용자는 상위 5개와 더 넓은 후보 범위에서 정답이 포함되는 비율을 보고, 관련 조문이 낮은 순위에 밀리는 문제를 리랭커로 보완하려 했다고 설명했다. 50 또는 100인지 기억이 불확실하다고 했으므로, 숫자는 실제 Recall@50 보고서로 확인했다.

KURE 500문자·법률 쟁점 질의의 Recall@5 31.39%와 Recall@50 56.57%는 당시 도입 판단의 근거다. 두 값의 차이는 리랭커 적용 전후 개선폭이 아니다. 공유 대화 당시에는 전후 실험을 찾지 못했지만 10월 31일 실험 브랜치에 직접 비교가 추가됐다. 후보 안의 순위와 후보 밖 누락을 구분한 최신 결과는 [검색 평가 검토](MoleLaw_커밋검토_20261031_검색평가.md)를 따른다.

## 추론 대기열: 속도 향상보다 요청을 대기시켜 실패 줄이기

사용자는 법령 벡터를 한 번 생성해 고정하기보다 계속 갱신하는 구조를 염두에 뒀고, 문서·질문 임베딩이 같은 단일 추론 자원을 사용하면 대기 시간이 길어질 수 있다고 설명했다. 병렬 처리를 넣은 의도는 추론 자체의 가속보다 요청을 대기시키고 손실을 줄이는 데 있었다고 명시했다.

현재 코드의 공유 추론 잠금·실행 슬롯·제한된 대기열은 그 의도를 담은 구현이다. 그러나 대기 슬롯 4개·5초 제한을 초과하면 503을 반환하므로 무손실·영속 수용을 보장하지 않는다. 혼합 부하의 33건 중 14건 대기 만료는 실제 모델 직접 호출 결과이며, 문서 재색인과 사용자 검색 전체가 함께 실행된 시험과 다르다. 자원·입력·구간·성공/거부 지표는 [부하 검증](MoleLaw_커밋검토_20261031_부하검증.md)에 남겼다.

사용자는 **503 이후 대응을 후속 개선 과제에 두고 싶다**고 밝혔다. 제한적 재시도·백오프·중복 방지·우선순위·추론 자원 분리·작업 영속화는 검토 방향이며, 대화에서 어시스턴트가 제시한 모든 방안을 사용자가 확정하거나 구현했다고 해석하지 않는다.

## 인증: 자원 제약과 민감한 상담의 다중 기기 사용 우려

사용자는 메모리 제약과 향후 기능 분리를 고려해 JWT를 선택했고, 민감한 개인 경험이 여러 기기에서 사용되는 것을 줄이기 위해 단일 접속을 원했다고 설명했다. 이는 설계 의도이며 JWT 사용 자체가 메모리를 줄였거나 MSA를 운영했다는 측정·운영 근거는 아니다.

최신 Refresh 문서는 로그인 family별 폐기와 사용자 전체 폐기를 지원하지만, 최대 활성 세션 제한은 후속 범위로 기록한다. 따라서 ‘단일 접속 강제 구현’·‘다중 기기 유출 방지 달성’으로 쓰지 않는다. 기존 Access는 로그아웃 후 만료까지 최대 5분 유효할 수 있다는 제약도 유지한다.

## 이력서 반영 원칙

사용자 발언은 **왜 그 선택을 했는지**의 근거, 커밋은 **무엇을 바꿨는지**의 근거, 실행 보고서는 **어디까지 확인했는지**의 근거로 사용한다. 공유 대화의 요약만으로 품질·속도·안정성 개선을 단정하지 않는다. 최신 작성 내용은 [의사결정 요약](MoleLaw_의사결정.md), 과거 커밋은 날짜별 검토 문서로 연결한다.
